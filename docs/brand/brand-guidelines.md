# XMem — 로고 가이드 (요약판)

> 한두 페이지로 유지한다. 비디자이너가 읽는 문서다. "하지 마라"보다 "이렇게 해라"를 먼저 쓴다.

## 1. 로고

- **아이디어**: 메모리 맵 — 길이와 위치가 제각각인 영역들을 슬레이트 타일에 새긴 형태. XMem의 핵심 화면(주소 공간 맵)을 그대로 아이콘으로 옮긴 마크다.
- **버전**: 기본(가로 락업) · 세로(스택) · 기호 단독 · 워드마크 단독 · 앱 아이콘(강조 슬롯 포함/미포함)
- **정본 파일**(현재 로컬): `final-symbol.svg`(기호) · `final-symbol-small.svg`(소형 컷) · `final-horizontal.svg` / `final-stacked.svg` / `wordmark.svg`(락업) · `app-icon.svg`, `app-icon-accent.svg`(앱 아이콘) · `favicon-source.svg`(파비콘 소스)
- **내보낸 세트**: `kit/` — SVG + PNG(16~1024), `favicon.ico`, `favicon-16/32/48.png`, `apple-touch-icon.png`, `icon-192/512.png`, `maskable-512.png`, `favicon.svg`, `site.webmanifest`, `head-snippet.html`
- 화면에는 RGB/SVG, 인쇄물에는 CMYK(PDF) 버전을 쓴다.

## 2. 클리어 스페이스 (여백)

로고 사방에 **기호 높이의 1/4** 만큼 빈 공간을 둔다. 로고가 커지면 여백도 같이 커진다 — 고정 거리를 쓰지 않는다.

## 3. 최소 크기

| 버전 | 화면 | 인쇄 |
|---|---|---|
| 가로 락업 | 폭 96 px 이상 | 폭 25 mm 이상 |
| 세로 락업 | 폭 72 px 이상 | 폭 20 mm 이상 |
| 기호 단독(4슬롯) | 24 px 이상 | 높이 7 mm 이상 |
| 기호/파비콘(3슬롯) | 16 px 이상 (`favicon-source.svg`) | 높이 5 mm 이상 |

16 px 이하에서는 반드시 3슬롯 소형 컷을 쓴다. 4슬롯 정본을 축소하지 않는다.

## 4. 색

| 이름 | HEX | RGB | CMYK | Pantone(근사) |
|---|---|---|---|---|
| 그래파이트 (기본/잉크) | `#1B1D20` | 27 / 29 / 32 | 15 / 9 / 0 / 88 | Black 6 C |
| 어센트 블루 (강조 슬롯 전용) | `#4C8DFF` | 76 / 141 / 255 | 70 / 45 / 0 / 0 | 2727 C |
| 페이퍼 (배경) | `#FFFFFF` | 255 / 255 / 255 | 0 / 0 / 0 / 0 | — |

그래파이트는 GUI 다크 테마의 패널 색과 같다. 화면 UI와 아이콘의 색을 맞춰 두면 자연스럽다.

**승인된 조합**: 흰 배경 위 그래파이트 · 그래파이트 타일 위 흰 슬롯 · 짙은 배경 위 흰색/반전 락업 · 그래파이트 단색 위 어센트 슬롯 하나(앱 아이콘 전용).
사진 위에는 차분한 영역에 흰색·검정 버전을 놓거나, 타일(둥근 사각) 안에 넣어 쓴다.

## 5. 타이포그래피

- **워드마크**: 현재 리뷰본은 Segoe UI Semibold로 조판돼 있다(탐색용). 배포용으로는 라이선스가 자유로운 폰트로 아웃라인해야 한다 — 권장: **Inter SemiBold** 또는 **IBM Plex Sans SemiBold**(둘 다 OFL).
- **UI**: 시스템 폰트(Segoe UI / Malgun Gothic). 웹 폴백: `system-ui, "Segoe UI", "Malgun Gothic", sans-serif`
- 폰트 라이선스는 로고 사용을 허용해야 한다. Microsoft 폰트는 재배포가 제한되므로 최종 산출물에 쓰지 않는다.

## 6. 이렇게 해라

- 슬롯의 **길이와 순서를 그대로** 쓴다 — 그 불규칙함이 메모리 맵이라는 정체성이다.
- 어센트 슬롯은 앱 아이콘에서 **한 곳만** 강조한다(앱 아이콘 4슬롯 기준 두 번째 슬롯).
- 어두운 배경에서는 반전(흰 타일/흰 슬롯) 버전을 쓴다.
- 락업의 비율·간격은 마스터 SVG를 그대로 복사해서 쓴다.
- 타일 없이 슬롯만 쓸 때는 잉크(그래파이트) 단색으로 쓴다.

## 7. 이건 하지 마라

늘리거나 찌그러뜨리지 않는다 · 팔레트 밖 색으로 바꾸지 않는다 · 회전하지 않는다 · 그림자·테두리·그라디언트·효과를 넣지 않는다 · 슬롯 개수·길이·순서를 바꾸지 않는다 · 어센트 슬롯을 다른 색/위치로 옮기지 않는다 · 워드마크를 폰트로 다시 타이핑해 쓰지 않는다(마스터를 쓴다) · 타일 밖으로 슬롯을 빼지 않는다.
