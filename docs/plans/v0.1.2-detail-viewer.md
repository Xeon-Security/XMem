# v0.1.2 상세 뷰어 Implementation Plan (실행 기록)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GUI에서 메모리맵·모듈·스레드의 상세 정보(hex, 디스크/메모리 PE 비교, 스레드 시간)를 깊게 볼 수 있게 하고, 모든 실패 경로에 사람이 읽는 오류 라벨을 붙인다.

**Architecture:** 백엔드 모델 확장(`MemoryRegion.allocation_base`, `PeInfo.time_date_stamp`+`parse_pe_file`, `thread_times`) + GUI 상세 패널 3종(맵/모듈/스레드, 표 행 클릭 → 하단 리사이즈 패널) + 공통 오류 라벨(`crates/xmem-gui/src/error.rs`).

**Tech Stack:** Rust, windows-rs 0.62, goblin 0.10, egui/eframe 0.36.2, egui_extras, rfd.

**Spec:** `docs/gui-design.md` (v0.1.2 상세 패널 항목)

## Self-Review Notes

- 상세 조회는 태스크 스레드에서 자체 `LiveProcess::open`을 사용해 UI 스레드 borrow/수명 문제를 회피했다.
- 스레드 시간은 Windows 타이머 틱(~15.6 ms) 양자화로 갓 시작한 스레드가 0으로 보일 수 있어 테스트가 폴링한다.
- 디스크 PE 파싱은 goblin의 파일 오프셋 기준 파싱을 그대로 사용하되 64 MiB 상한을 두고, 실패 시 메모리 헤더 결과만 출처 라벨과 함께 표시한다.
